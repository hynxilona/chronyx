01

Three jobs, no overlap

Most consensus designs ask one mechanism to do everything. This one does not.

PoHorders

A clock nobody can argue with

Each tick hashes the one before it. To produce tick n you must have produced tick n−1, so the sequence itself is the proof that time passed. Two nodes that agree on the hash agree on the order — no voting, no timestamps to trust.

PoAfinalizes

Finality in one slot

A small validator set takes slots round-robin. One signed block per slot, 400 ms apart, quorum 3 of 4. Boring on purpose: the failure modes are short enough to read in one sitting.

PoWadmits

Work, not capital

Joining the validator set costs hashcash-style work that is expensive to fake and instant to verify. No token purchase, no allowlist, no permission from a foundation. Proofs work today; wiring them into admission is the next milestone.
