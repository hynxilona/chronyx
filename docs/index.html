A blockchain written from scratch in Rust. No framework, no VM, no ERC-20. 400 ms slots, native accounts, an append-only ledger, and a fixed 600,000,000 CHRONYX supply.

Three mechanisms, one job each

PoA alone is permissioned. PoW alone is slow. PoH alone is just a clock.

PoH · orders

A sequential SHA-256 chain proves time passed. Tick 50 ms, eight ticks per slot, replayable by anyone.

PoA · finalizes

Round-robin leaders over a known validator set. One signed block per slot, 400 ms finality.

PoW · admits

Joining costs work, not capital. Hashcash-style proofs, mined in seconds and verified in microseconds.

600,000,000 CHRONYX, fixed

Solana runs ~638M total and ~592M circulating. Chronyx sits between them, and never mints again.

Run a node

Rust stable. Two commands to follow the chain, one more to join it properly.

# build
git clone https://github.com/hynxilona/chronyx
cd chronyx
cargo build --release --workspace

# follow the seed node
./target/release/chronyx devnet join http://SEED_HOST:8899 \
  --peer SEED_HOST:9000 --dir ./my-node

# start
./target/release/chronyxd --config ./my-node/node.toml

Check that the genesis hash printed by join matches the seed operator's. Different hash, different chain.
