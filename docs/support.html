02

Ways to fund it

In order of preference, because they differ in strings attached.

Recurring

GitHub Sponsors

Public, cancellable, no influence over the protocol. The Sponsor button lives on the repo; one-time and monthly both work.

Infrastructure

Validator sponsorship

Pay for a bootstrap slot for a year. Your name in cluster validators and the README. No say in consensus, ever.

Work

Bounties

Small, scoped, paid on merge: an RPC route with tests, a fuzz target, a client library. The cheapest useful work money can buy.

One-off

Direct

A donation address is published once the wallet is set up, and every inflow is listed. No address is live yet — do not send anything to a look-alike.

03

Where it goes, in writing

Transparency is a file in the repo, not a promise in a post.

  • Every expense over $100 is listed

    Date, amount, purpose, in docs/SPONSORS.md. If a vendor asks not to be named, the line says "vendor, name withheld" and keeps the amount.

  • Every audit is published in full

    Including the findings that make the maintainer look bad. A report with no findings is a report nobody read.

  • Running out gets said out loud

    If the money stops, the roadmap says so instead of shipping a half-audited mainnet and hoping.

04

What this is not

The list matters more than the pitch.

  • Not a presale, not a private round, not a SAFT
  • Not an airdrop, and no points program
  • Not an investment, and no token will be sold to you
  • No listing fees, market makers or paid shills
  • No sponsor gets protocol control or supply
  • No mainnet date will ever be announced before an audit

Current status: unfunded. Applying to GitHub Sponsors and two grant programs, audit quotes requested. This page changes the day something changes, not when it is convenient.

PoH orders. PoA finalizes. PoW admits. A Rust chain with a fixed supply and no framework to hide behind.
