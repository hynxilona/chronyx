Supply

Six hundred million.
Then never again.

Every CHRONYX that will ever exist was created in the genesis file. There is no mint function to call, no inflation schedule to tune, and no team allocation waiting to unlock. The number is a constant, and a test fails if it moves.

01

Where the devnet supply sits

One genesis file, four validators, one faucet. Everything adds up to the cap.

HolderCHRONYXShareNotes
Devnet faucet500,000,00083.3%open, capped at 1,000 per request

Devnet tokens are worthless. The faucet exists so people can move coins around while testing. Nothing here is for sale, and nothing here will carry over to mainnet.

02

Count it yourself

One CHRONYX is one billion quanta. The node stores integers; this converts.

quanta ↔ CHRONYX1 CHRONYX = 1,000,000,000
quanta—
CHRONYX—

Rounded to the nearest quantum, because fractions of a quantum do not exist.

03

How the cap survives a pull request

Policy that lives in comments gets deleted. This one lives in CI.

An invariant test

Genesis may not exceed the cap, transfers may not create quanta, and a rejected transaction changes nothing.

crates/core/tests/invariants.rs
assert_eq!(state.total_supply(), cap_quanta());

state.apply(&tx).unwrap();
assert_eq!(state.total_supply(), funded);

A source guard

CI greps the tree for anything that creates quanta outside the account module, and for the supply constants moving.

scripts/guard-supply.sh
$ bash scripts/guard-supply.sh
ok  supply guard: no minting paths,
    constants intact

A change that legitimately needs an exception is not a code change — it is a monetary-policy change. It gets an issue, a review, and the guard script edit in the same diff so nobody can miss it.

04

The plan for mainnet

Documented so it can be argued with. Not implemented, not distributed.

BucketShareCondition
Community and incentives55%earned by running, testing, building
Validator bootstrap15%operators who were up during devnet
Treasury15%audits, infrastructure, bounties
Team10%4-year vest, no unlock before audit
Liquidity5%only if a market exists at all

None of that exists yet. There is no mainnet token, no sale, and no date. The audit comes first; Support explains what it costs and where the money goes.

PoH orders. PoA finalizes. PoW admits. A Rust chain with a fixed supply and no framework to hide behind.
